Filmsammlung

Daten vorbereiten

Macht aus deiner Dashboard-Sicherung die Datei sammlung.json für die Website. Alles passiert nur hier in deinem Browser – die Sicherung wird nirgendwohin hochgeladen.

  1. Sicherung wählen

    Im Dashboard unter Einstellungen → Daten → „Sicherung speichern“.

  2. Was soll auf die Website?

    Titel, Jahr, Cover, Genre, Regie, Laufzeit und die IMDb-Angaben sind immer dabei. Dein OMDb-Schlüssel, Favoriten und Einstellungen kommen nie mit.

    Wahlweise Angaben

    Die Website ist für jeden mit dem Link sichtbar.

  3. Passwort (wahlweise)

    Besucher sehen die Sammlung erst, wenn sie das Passwort eingeben; danach merkt sich ihr Browser die Freischaltung. Das ist nur ein Sichtschutz: Wer die Adresse der Datei sammlung.json kennt, kann sie trotzdem abrufen.

  4. Datei speichern

    Danach im Projektordner die Datei data/sammlung.json durch die neue ersetzen, in GitHub Desktop committen und „Push origin“ – nach ein, zwei Minuten ist die Website aktuell.
